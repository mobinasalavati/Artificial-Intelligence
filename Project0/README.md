# Bank Term Deposit Prediction (EDA)

## Description
This project focuses on Exploratory Data Analysis (EDA) of a bank customer dataset. The goal is to analyze customer attributes (age, job, marital status, etc.) to predict their likelihood of subscribing to a term deposit campaign.

## Key Features
- Data cleaning and preprocessing.
- Exploratory data analysis on customer demographics.
- Feature relationship mapping.
