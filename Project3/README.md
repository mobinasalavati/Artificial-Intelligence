# Naive Bayes Text Classification

## Description
A Natural Language Processing (NLP) project focused on classifying Persian articles from Digikala Mag. It uses a Naive Bayes Classifier to categorize content based on text analysis.

## Key Features
- Persian text preprocessing and tokenization.
- Implementation of Naive Bayes for multi-class classification.
- Performance evaluation on real-world article data.
