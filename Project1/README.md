# Gandalf Pathfinding AI

## Description
An implementation of search algorithms where Gandalf navigates a grid map to rescue members of the Fellowship. The pathfinding must account for Orc territories and military patrols while optimizing the route.

## Key Features
- Grid-based map navigation.
- Implementation of search algorithms (BFS, DFS, A*).
- Constraint-based movement and patrol avoidance.
