# Game AI and Genetic Algorithms

## Description
A two-part project exploring adversarial search and evolutionary computation.

### Connect 4 AI
Implementation of a game-playing agent for Connect 4 using Minimax and Alpha-Beta pruning to optimize move selection.

### Genetic Cryptanalysis
An evolutionary approach to message decryption. The algorithm evolves a population of keys to find the optimal mapping for a given cipher text.
