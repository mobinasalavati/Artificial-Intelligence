# Artificial Intelligence

Computer assignments for the Artificial Intelligence course at the University of Tehran (Spring 1401 / 2022), implemented in Python and Jupyter Notebook.

## Projects

| Project | Topic |
|---|---|
| [Project0](Project0) | Bank term deposit EDA and a simple Gaussian statistical classifier (pandas/numpy, vectorized) |
| [Project1](Project1) | Uninformed & informed search — BFS, IDS, A*, and weighted A* on a grid pathfinding problem |
| [Project2](Project2) | Adversarial search (Minimax + alpha-beta pruning for Connect 4) and a genetic-algorithm substitution-cipher decoder |
| [Project3](Project3) | Naive Bayes text classification of Persian news articles, implemented from scratch |
| [Project4](Project4) | Music genre classification with Scikit-Learn — KNN, Decision Tree, and Random Forest |
| [Project5](Project5) | Neural networks — from-scratch MLP (Phase 1) and a deep learning framework (Phase 2) |

Each project folder has its own README with problem description, implementation details, and tech stack.
